# Step 01 - SD Card Preparation

## Goal
Prepare a compatible SD card for Nintendo 3DS modding so the system can properly read homebrew and custom firmware files.

---

## Device Info
- Console: Nintendo 3DS XL (Super Smash Bros. Edition)
- SD Card: microSD (formatted to FAT32)
- Device used for Formatting: macOS

---

## What I did
1. Removed the SD card from the 3DS
2. Insterted to Mac, using adapter
3. Copied 3DS folder files to safe location on Mac
4. Formatted the card to FAT32 (required for 3DS)
5. Copied 3DS folder files into SD card (kept on Mac for safety)
6. Reinserted the SD card into the console
7. Verified the 3DS recognized the card

---

## Issues Encountered
- Initially thought the SD slot was missing (tutorials online were for a different model with a different location)
- common ejection warnings about card still in use (never ignored, always waited)

---

## Final Outcome
- SD card detected by 3DS
- Card ready for

## Notes
- Always eject SD card properly, do not risk harming data
- FAT32 is required, exFAT will not work
- A New 3DS XL requires a similar but different process to mod
